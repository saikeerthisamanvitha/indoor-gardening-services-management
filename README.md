Indoor Gardening Services Management (IGSM)

Project Overview
Indoor Gardening Services Management (IGSM) is a ServiceNow application designed to manage indoor gardening service requests in an organized and structured way.
The project focuses on request submission, approval workflows, technician assignment, request tracking, and service-level agreement (SLA) management.

Objectives
- Simplify indoor gardening service request submission.
- Organize plant care service requests.
- Support manager approval and technician assignment workflows.
- Track request status throughout its lifecycle.
- Apply access controls to manage user permissions.
- Configure SLAs to support timely service handling.

Key Features
- Service Request Management:Capture plant care requests and related details.
- Record Producer:Provide a form for submitting garden service requests.
- Flow Designer:Configure workflow automation for approvals and assignments.
- Groups and Roles:Organize managers, technicians, and requesters.
- SLA Management:Configure response and completion SLA rules.
- Business Rules and Client Scripts:Support data validation and form behavior.
- Access Control Lists (ACLs):Configure record access permissions.

Technology Stack
- ServiceNow Platform
- ServiceNow Studio / Scoped Applications
- Flow Designer
- Service Catalog and Record Producers
- Business Rules, Client Scripts, and UI Policies
- Service Level Management (SLAs)
- Access Control Lists (ACLs)
